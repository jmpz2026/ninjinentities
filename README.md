# ninjinentitiesRecompiled

Ninjin Entities 1.2.7.4 (Hedaox) decompiled back to source for Minecraft 1.7.10 Forge,
plus the new NPCs of [ninjinentities-Unofficial](https://github.com/kaixiten/ninjinentities-Unofficial) 1.4.53
added on top without changing or removing any 1.2.7.4 content.

## Stack
- Minecraft 1.7.10, Forge 10.13.4.1614
- Java 8, Gradle 4.5 + ForgeGradle (anatawa12 fork)
- Needs Dragon Block C 1.4.85 + JRMCore 1.3.51 at runtime

## Build
```bash
./gradlew build
```
Output: `build/libs/ninjinentities-1.2.7.4.jar`.
